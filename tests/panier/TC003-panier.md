
# TC003 - Ajout d'un produit au panier

 

## Précondition

L'utilisateur est connecté et se trouve sur la page des produits.

 

## Étapes

1. Sélectionner un produit.

2. Cliquer sur Add to cart.

3. Cliquer sur l'icône du panier.

4. Vérifier le contenu du panier.

 

## Résultat attendu

Le produit sélectionné apparaît dans le panier.
