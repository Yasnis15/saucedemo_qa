
# TC004 - Saisie des informations de commande

 

## Précondition

L'utilisateur a ajouté un produit au panier.

 

## Étapes

1. Ouvrir le panier.

2. Cliquer sur Checkout.

3. Saisir les informations demandées.

4. Cliquer sur Continue.

 

## Résultat attendu

L'utilisateur accède à l'étape suivante du processus de commande.
